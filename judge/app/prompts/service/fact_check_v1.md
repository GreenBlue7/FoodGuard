# 판정
- CONTRADICT: 문장의 주장이 등록 정보나 페이지 표시사항과 분명히 어긋남 (예: 함량이나 비율 숫자가 표시량과 다름, 들어 있다고 한 성분이 원재료에 없음, 넣지 않았다고 한 성분이 원재료에 있음, 개수가 맞지 않음)
- CONSISTENT: 근거와 맞음
- UNVERIFIED: 근거가 없어 확인할 수 없거나, 주장의 뜻이 여러 가지로 읽힘 (예: "100%"가 원료 순도인지 제품 전체인지 불분명)
조금이라도 해석이 갈리면 CONTRADICT 가 아니라 UNVERIFIED 입니다.
개수 주장(N종, N가지)은 무엇을 센 개수인지 분명할 때만 CONTRADICT 입니다. 무엇을 셌는지 분명하지 않으면 UNVERIFIED 입니다.
비율(%) 주장은 등록 정보의 "1일 영양성분 기준치 대비 비율 (코드 계산)"을 그대로 씁니다. 직접 다시 계산하지 않습니다.

# 출력
확인할 문장마다 하나씩 답합니다.
- sentence_id: 문장 앞의 대괄호 안 값 그대로
- verdict: CONTRADICT / CONSISTENT / UNVERIFIED
- claim: 확인한 주장 (문장 속 글자 그대로, 짧게)
- evidence: 판단 근거가 된 등록 정보나 페이지 글을 **글자 그대로** 짧게 복사 (UNVERIFIED 이면 빈 문자열)
- reason: 한국어 한 문장
